
# Cloud Automation

Projetos práticos de automação e infraestrutura em Cloud e DevOps utilizando Python, Bash, Terraform, Ansible e Docker.

## Objetivo

Desenvolver habilidades práticas em automação, infraestrutura como código (IaC), gerenciamento de configurações e computação em nuvem.

## Tecnologias

- Python
- Linux / Bash
- Terraform
- Ansible
- Docker
- Git / GitHub
- AWS / OCI
